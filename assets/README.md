# Assets

This folder contains placeholders and a recommended spec list. Replace placeholders with your real assets.

Recommended filenames:
- hero-1600x900.jpg (or .webp) — Desktop hero image, 16:9, 1600×900
- hero-800x450.jpg — Tablet/mobile hero image, 800×450
- avatar-maria.jpg — 400×400
- avatar-arun.jpg — 400×400
- avatar-sarah.jpg — 400×400
- laura-kim-400x400.jpg — team headshot
- logo.svg — primary logo (vector)
- trust-logo-1.svg, trust-logo-2.svg, trust-logo-3.svg — partner/trust logos (SVG)

Image tips:
- Export hero in WebP for best performance, fallback JPEG if needed.
- Keep file sizes under 200KB for hero where possible (use compression).
